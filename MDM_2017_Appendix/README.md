# Original files (as published, 2017-2019)

These are the files released with the paper and archived on Zenodo as version 1.0.0 ([doi:10.5281/zenodo.3263876](https://doi.org/10.5281/zenodo.3263876)). They are kept unchanged for the record.

**For new work, use the maintained code in [`R/`](../R) and [`analysis/`](../analysis)**, which runs from the repository root, sets random seeds, and includes the fixes listed in [NEWS.md](../NEWS.md).

Known issue in these files: `Appendix_EVSI_GA_normal_weibull_mcmc.R` refers to an undefined JAGS variable `v` and does not run. See `analysis/04_appendixC_n0_mcmc.R` for the corrected version.

The `ESS_calculator_*.R` files are exploratory scripts for estimating the effective sample size; they are not part of the paper.
